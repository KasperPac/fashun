# Test script: KAS-174, Fashun selfie colour reading

Written by QA from KAS-174 "What done looks like" and the approved wording on KAS-175 only. I didn't read the Engineer's branch, and nothing here says how to build the fix.

**Markers**
- `automated`: the Engineer writes a test for it, and it runs with the repository's tests.
- `preview`: run by hand on the preview or test copy, through the real screens. Use computer-generated test faces only, never a real person's photo.
- `live-safe`: safe to run on production after the merge. Creates no data, costs nothing and touches no personal data.

**The two messages (word for word)**
- **Photo message** (outcome 3, unchanged): "We couldn't read your colours from that photo. Try again in daylight with your face filling most of the frame."
- **Service message** (KAS-175, approved): "We couldn't read your colours just now. That's on our side, not your photo, so try again in a few minutes."

**"Logs"** means the server's own output: the terminal on the test copy, the Vercel runtime logs on preview and live.
